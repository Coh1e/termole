# T20 资源有界验证（初步）

## 实现上限

- 回滚历史：1000 行（`TERMOLE_SCROLLBACK_LINES`），超出丢弃最旧行。
- 事件队列：256 条；标题事件合并，退出/错误事件在洪泛时优先保留。
- 参数数组、OSC/字符串状态、终端单元的组合长度有上限。
- 每个 Session 的进程树放入 Job Object（`KILL_ON_JOB_CLOSE`）；View 销毁不终止 Session，Session 销毁/terminate 清理进程树。
- 无 View 时 reader 仍消费输出，仅保留有界终端状态；不缓存完整原始输出流。

## 自动验证

- `t03_t05_session`：400 次标题+响铃洪泛后事件队列 ≤256 且退出事件存在；1100 行输出历史精确 1000 行；View 销毁后会话继续、重附加；5 个并发 Session 各输出 1500 行，历史仍有界并全部停止。
- `t20_soak`：连续 3 个 Session 各 200,000 行、无 View，历史仍 ≤1000 行；本进程 working set 增长上限 64 MiB（实测约数 MiB），全部正常停止。
- `t03_cli_exit`：失败退出保留窗口、关闭后返回退出码；进程树清理由既有 T01 测试覆盖。
- `t15_picker` / `t15_embedded_picker`：临时文件在成功/失败路径删除；嵌入 picker 的 stdout 提前关闭不会挂死。
- 长时标题/响铃交替洪泛尚无独立 soak；picker 结果背压（调用方慢读）尚未断言。
