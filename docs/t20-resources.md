# T20 资源有界验证（初步）

## 实现上限

- 回滚历史：1000 行（`TERMOLE_SCROLLBACK_LINES`），超出丢弃最旧行。
- 事件队列：256 条；标题事件合并，退出/错误事件在洪泛时优先保留。
- 参数数组、OSC/字符串状态、终端单元的组合长度有上限。
- 每个 Session 的进程树放入 Job Object（`KILL_ON_JOB_CLOSE`）；View 销毁不终止 Session，Session 销毁/terminate 清理进程树。
- 无 View 时 reader 仍消费输出，仅保留有界终端状态；不缓存完整原始输出流。

## 自动验证

- `t03_t05_session`：400 次标题+响铃洪泛后事件队列 ≤256 且退出事件存在；1100 行输出历史精确 1000 行；View 销毁后会话继续、重附加；新增 5 个并发 Session 各输出 1500 行，历史仍有界并全部停止。
- `t03_cli_exit`：失败退出保留窗口、关闭后返回退出码；进程树清理由既有 T01 测试覆盖。
- `t15_picker`：picker 临时文件在成功/失败路径删除；结果/诊断分离。
- 长时输出、picker 管道提前关闭、标题/响铃交替洪泛尚无独立 soak 测试；也没有内存趋势断言。

## 未完成

- picker 大结果背压、调用方提前关闭 stdout、候选输入提前结束的自动用例。
- 多 Session 反复创建/销毁的进程句柄计数与失效回调检查。
- 未增加常驻服务或后台守护进程。
