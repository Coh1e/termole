# Termole 首版任务拆分

来源：[实施规格 #1](https://github.com/Coh1e/termole/issues/1)。状态：已确认并发布为 GitHub 子任务 #2–#25；24 项标签、原生子任务层级及 46 条阻塞关系已逐项核对。对应链接见 [任务索引](issue-index.md)。T 编号为本地讨论编号，不是 GitHub Issue 编号。

每项完成应可单独演示或通过公开宿主/真实 CLI 边界验收。首项已有 CMake 与探针基础，无需先做纯内部层重构；产品实现必须与比较探针分离。后续任务沿用规格 #1 的平台、语言、许可、复用约束和非目标。

## T01：在独立窗口和宿主内运行最小 PowerShell 终端

**Blocked by:** 无，可立即开始。

**What it delivers:** 通过同一 DLL、C ABI 和 C++23 包装，在独立窗口和最小原生宿主内运行可交互 PowerShell。

**Acceptance criteria:**

- [ ] 两种入口复用真实 Session/View，具备基础 VT 文字/光标显示、键盘输入、Enter、退格和窗口尺寸同步，不使用 MockTerm 或静态快照冒充终端。
- [ ] 无配置启动优先使用 PowerShell 7，否则 Windows PowerShell；可输入并执行基础命令并看到输出。
- [ ] 宿主通过公开接口创建子 HWND；UI 线程、基础数据所有权、版本检查和错误返回有明确契约。
- [ ] 关闭/退出可收尾且不遗留本会话进程；基础 UI 不依赖顶层窗口内的终端协议逻辑。
- [ ] 落实满足该切片的最小 VT 实现及来源说明；依赖扩张时研究成熟实现，不默认引入 Contour/libghostty-vt；C++23/CMake/FetchContent/Ninja 构建和双入口行为测试通过。

**规格用户故事覆盖：** 1–2、19、38–40、44–47、56–58（基础）。

## T02：通过 CLI 和宿主准确启动任意目标程序

**Blocked by:** T01。

**What it delivers:** 从 CMD、PowerShell 或宿主启动指定程序，保留参数、工作目录和环境。

**Acceptance criteria:**

- [ ] 支持目标程序分隔符，之后不解释 Termole 选项；空格、引号、空参数和 Unicode 的逻辑参数可由受控子程序核对。
- [ ] CLI 与宿主可指定工作目录及环境变量，不修改调用方全局环境。
- [ ] Shell 负责组合管道，Termole 不引入命令语言；无效选项、缺失程序和启动失败有明确诊断及失败状态。
- [ ] 多个独立实例/宿主会话互不影响；从 CMD 与 PowerShell 的真实调用验证等待和标准句柄行为，包括无控制台启动。

**规格用户故事覆盖：** 3–7、29。

## T03：正确处理失败退出、最后输出和进程树关闭

**Blocked by:** T02。

**What it delivers:** 用户能看见失败程序的最后输出和退出码，关闭终端后不会遗留本会话进程。

**Acceptance criteria:**

- [ ] 普通终端正常退出默认关窗、非零退出保留画面及退出码；显式保留窗口设置可覆盖，宿主自行决定展示。
- [ ] 主程序尾部标记排空后才报告完成；派生进程持有输出句柄时有可说明、可测试的有界收尾策略。
- [ ] 显式终止、关闭独立窗口和宿主退出清理本会话进程树，不终止其他会话；不支持脱离会话保活。
- [ ] 启动失败、自然退出、用户关闭和强制终止均有结构化结果，异常路径不会无限等待。

**规格用户故事覆盖：** 21–24。

## T04：关闭视图后继续运行并恢复会话画面

**Blocked by:** T01。

**What it delivers:** 宿主关闭终端页面后程序继续运行，重新打开页面恢复当前画面和有限历史。

**Acceptance criteria:**

- [ ] 销毁 View 不终止 Session；持续输出程序在无 View 时仍被消费，不因管道填满卡死。
- [ ] 允许同一 Session 重建 View；当前画面与保留历史可见，历史容量上限明确且可验证。
- [ ] 一个 Session 同时只允许一个 View；重复附加返回可解释错误，多组 Session/View 互不干扰。
- [ ] 通过公开宿主接口测试销毁、等待输出、重新附加和最终终止；不以快照引用寿命测试替代真实会话。

**规格用户故事覆盖：** 40–43。

## T05：宿主接收状态事件并安全处理销毁

**Blocked by:** T03。

**What it delivers:** 宿主能响应标题、响铃、退出和错误，并在事件发生时安全查询或关闭会话。

**Acceptance criteria:**

- [ ] 提供状态、尺寸、标题、退出码查询及标题变化、响铃、退出、错误事件。
- [ ] 事件在宿主可调度队列交付，后台 I/O 不直接调用宿主 UI；事件处理内终止会话有定义行为。
- [ ] 排队后销毁 View/Session/context、过期句柄和 ABI 版本不匹配明确处理，无失效对象回调、异常穿透或死锁。
- [ ] 库分配的数据由库释放，异步保留输入由库复制；C++ 包装复用 C ABI，库不擅自弹窗。
- [ ] 记录队列容量与合并/丢弃规则，保证重要退出/错误可观察且事件洪泛不无限占用内存。

**规格用户故事覆盖：** 45–50、51–52（原生契约）。

## T06：在独立和嵌入终端中操作全屏 fzf

**Blocked by:** T02。

**What it delivers:** 普通终端模式下运行真实 fzf，完成导航、输入筛选、选择和退出，恢复此前画面。

**Acceptance criteria:**

- [ ] 真实 fzf 无需修改即可显示全屏列表，方向键、必要组合键和字符输入按当前终端模式编码。
- [ ] 实现此路径需要的 VT/SGR、清屏、光标定位/形状、alternate screen 进入退出及尺寸变化，不声称支持所有高级协议。
- [ ] 退出后正确恢复主屏幕及光标；独立入口和公开宿主入口均通过固定版本交互用例。
- [ ] 先验证纯终端交互，此项不宣称已经将选择结果返回调用脚本。

**规格用户故事覆盖：** 15–16、19、31（交互）。

## T07：正确显示和操作中文双宽文字

**Blocked by:** T01。

**What it delivers:** 中文和英文混排时，文字、光标、换行及调整尺寸保持正确网格占位。

**Acceptance criteria:**

- [ ] 正确消费分块 UTF-8 输入，处理被读取边界拆开的字符，不把协议字节当成文字。
- [ ] CJK 双宽占位、行末写入/删除、光标移动和调整尺寸有固定外部可观察用例。
- [ ] 默认系统等宽字体及中文缺字回退可用，不要求用户安装字体。
- [ ] 独立窗口和宿主显示真实子程序的混排输出，窄范围数据用例只用于定位必要的协议/宽度错误。

**规格用户故事覆盖：** 11–12、14（CJK）。

## T08：正确显示组合字符和 Emoji

**Blocked by:** T07。

**What it delivers:** 组合重音、变体选择符和常见 Emoji 序列不会使后续文字与光标错位。

**Acceptance criteria:**

- [ ] 给出首版支持的组合字符、Emoji/ZWJ 与变体序列样例，跨输入分块仍保持同一结果。
- [ ] 字体回退与字素/单元占位匹配，删除、覆盖、换行和尺寸变化不留下孤立残片。
- [ ] 真实终端与嵌入显示用例验证，不以普通 DirectWrite 多行文本图片代替终端网格验收。
- [ ] 未支持的高级呈现明确记录；不把单色回退误称为已完整支持彩色 Emoji。

**规格用户故事覆盖：** 12、14（组合/Emoji）。

## T09：在独立窗口和宿主中使用中文输入法

**Blocked by:** T07。

**What it delivers:** 用户可在终端中切换中文输入法、定位候选、提交或取消文字，并正确切换焦点。

**Acceptance criteria:**

- [ ] 真实 Windows IME 候选位置随终端光标变化，提交文本进入正确会话，取消不产生多余文字。
- [ ] 宿主控件与其他控件切换焦点后，按键和输入法状态不串到其他会话。
- [ ] 组合阶段与普通终端按键分离；最小宿主和独立窗口均有可复现的人工/自动混合验收。
- [ ] 记录输入法、系统和测试步骤，不能以发送 Unicode 文本 API 替代 IME 验收。

**规格用户故事覆盖：** 13、39。

## T10：调整字体主题并适应 DPI 变化

**Blocked by:** T07。

**What it delivers:** 用户通过 CLI 或宿主设置改变字体、字号、主题，窗口缩放后保持可读与可操作。

**Acceptance criteria:**

- [ ] 支持字体、字号、主题设置；默认主题跟随系统，使用系统字体及既有回退。
- [ ] 跨不同 DPI/缩放布局正确，字符尺寸、终端尺寸、光标与宿主坐标同步；记录已验证配置。
- [ ] 独立与嵌入入口复用外观操作，动态更新资源有清晰寿命，不依赖重启整个宿主。
- [ ] 通过真实绘制/布局及用户可观察结果验收，避免仅检查配置值。

**规格用户故事覆盖：** 10–12、19、39（显示/缩放）。

## T11：滚动选择并在终端和系统之间复制粘贴

**Blocked by:** T04、T08。

**What it delivers:** 用户能浏览历史、选择跨行及混合宽度文本，复制到系统或向终端粘贴。

**Acceptance criteria:**

- [ ] 实现滚动、选择、选中文本查询、主动复制和粘贴；Unicode 与跨行选择不拆坏字符。
- [ ] 有界历史与销毁/重建 View 的行为一致，滚动视口不错误改变底层运行中的会话状态。
- [ ] 独立窗口快捷操作和宿主公开能力均可用，多会话的选择和剪贴板操作不串线。
- [ ] 终端输出触发的剪贴板写入默认禁用；用户/宿主可显式授权，本地与远端序列规则一致。

**规格用户故事覆盖：** 17、48（选择）、53。

## T12：按终端模式处理鼠标和 bracketed paste

**Blocked by:** T06、T11。

**What it delivers:** 用户在 TUI 中使用鼠标与多行粘贴，同时仍能执行终端本地选择。

**Acceptance criteria:**

- [ ] 根据目标程序启用的模式编码鼠标事件，定义与本地文本选择的切换方式。
- [ ] 程序开启 bracketed paste 时发送正确边界，未开启时使用相应普通粘贴行为；按键输入不误作粘贴。
- [ ] 在真实 fzf/受控程序中核对点击、滚轮、拖动、多行文本和调整尺寸后的坐标。
- [ ] 独立与嵌入入口行为一致，不以只测试输入编码函数代替端到端验证。

**规格用户故事覆盖：** 16–18。

## T13：用 CLI 将 TUI 呈现为独立 Applet 小窗口

**Blocked by:** T02。

**What it delivers:** 用户指定网格、位置、居中、浮动、边框、透明度、标题和图标启动小工具。

**Acceptance criteria:**

- [ ] CLI 可表达字符网格大小、位置/居中、浮动、无边框、透明度、标题和图标；参数范围与冲突有明确规则。
- [ ] 用真实子程序核对启动网格，移动/调整窗口不破坏会话；无边框窗口仍有明确关闭和焦点行为。
- [ ] 仅 Window 外壳处理顶层属性；宿主保有自身窗口布局与焦点控制权。
- [ ] 非法值和失效图标等错误可解释；此模式本身不假装具有 picker 结果返回。

**规格用户故事覆盖：** 8–10（窗口属性）。

## T14：用 TOML 和 Profile 复现启动配置

**Blocked by:** T03、T10、T13。

**What it delivers:** 用户可以保存可复用 Profile，并通过 CLI 覆盖设置，配置出错时仍可选择启动。

**Acceptance criteria:**

- [ ] 默认值、用户配置、Profile、CLI 的覆盖顺序在实际启动外观、尺寸和退出行为上可观察。
- [ ] 无配置可启动；已有配置错误显示文件和位置，并允许使用默认配置启动；CLI 错误直接失败。
- [ ] 嵌入宿主可传相同设置而不被强制读取用户配置；Profile 是配置组，不是插件或应用包。
- [ ] 选择小型 TOML 实现或参考成熟方案，遵守依赖与许可原则；不引入 QuickJS。

**规格用户故事覆盖：** 25–29。

## T15：从调用脚本打开 fzf 弹窗并返回单选结果

**Blocked by:** T03、T06。

**What it delivers:** 真实 CMD/PowerShell 调用将候选送进弹窗，并收到未经修改 fzf 的单选结果。

**Acceptance criteria:**

- [ ] 提供显式 picker 模式，候选 stdin、结果 stdout、诊断 stderr 与 ConPTY 显示分离；不从最终画面猜结果。
- [ ] ASCII 单选、Escape、用户关闭、程序失败和工具缺失的结果及状态可由调用脚本判断。
- [ ] 正常转交目标退出码，冻结关闭视为取消及基础设施失败的表示，不承诺任意程序都有不冲突的专用数字。
- [ ] 真实 GUI/CLI 入口和调用方等待行为通过测试；helper 若采用，仅为内部细节，不要求修改 fzf。

**规格用户故事覆盖：** 30–33、36。

## T16：可靠返回多选、特殊字符和大规模选择结果

**Blocked by:** T08、T15。

**What it delivers:** 脚本可使用多选和 NUL 分隔，传输包含中文、Emoji、换行的候选及大量结果。

**Acceptance criteria:**

- [ ] 单/多选与 NUL 输入输出保留 fzf 原始字节及顺序，不追加换行、转码或排序。
- [ ] 复用并扩展既有八类验证：单选、多选、Escape、关闭、NUL、嵌入换行、中文/Emoji、超过管道容量的大输入。
- [ ] 新增大结果背压、调用方提前关闭结果管道、候选输入提前结束及取消时的清理用例，不永久等待。
- [ ] 从 CMD/PowerShell 实际脚本捕获 stdout/stderr 与退出状态，结果无绘制或诊断污染。

**规格用户故事覆盖：** 34–37。

## T17：在 CMD 和 WSL 中完成日常 Shell 交互

**Blocked by:** T03、T09、T12。

**What it delivers:** 用户能在独立和嵌入终端内运行 CMD、已安装的 WSL Shell，完成输入、粘贴、调整尺寸和退出。

**Acceptance criteria:**

- [ ] 固定 CMD/WSL 环境和版本，验证命令执行、中英文输出、键盘/IME、粘贴及尺寸更新。
- [ ] WSL 不由 Termole 安装；环境缺失和发行版启动失败有明确诊断。
- [ ] Shell 正常/异常退出及关闭窗口遵循已定策略，不影响其他 Windows 会话。
- [ ] 记录环境差异与回归步骤，修复该用户路径需要的兼容问题，不将 WSL fzf picker 纳入本项。

**规格用户故事覆盖：** 3、6、13、16–19（Shell 兼容）。

## T18：在 Neovim 和 Helix 中完成编辑任务

**Blocked by:** T08、T09、T12。

**What it delivers:** 用户在两种真实编辑器中完成打开、输入中英文、导航、选择/粘贴、调整尺寸、保存及退出。

**Acceptance criteria:**

- [ ] 固定两种编辑器版本和最小配置，提供独立与嵌入入口可复现的编辑流程。
- [ ] 覆盖 alternate screen、光标形状、必要键盘模式、中文 IME、组合/Emoji、鼠标与 bracketed paste。
- [ ] 保存文件内容正确，退出恢复原画面；修复用例发现的协议/网格问题。
- [ ] 高级协议是否加入以实际流程需要为依据，不能只凭上游宣称通过。

**规格用户故事覆盖：** 13–19（编辑器兼容）。

## T19：在 lazygit 中完成基本 Git 操作

**Blocked by:** T08、T12。

**What it delivers:** 用户能在终端内浏览仓库状态、导航面板、查看差异并退出 lazygit。

**Acceptance criteria:**

- [ ] 使用独立的临时测试仓库及固定 lazygit 版本，不改用户实际仓库内容。
- [ ] 独立与嵌入入口验证面板布局、颜色、中文路径、导航/鼠标及尺寸变化。
- [ ] 退出恢复主屏幕，错误可见，修复该路径所需兼容缺口。
- [ ] 记录可复现用例与证据，不在 Termole 内实现 Git 或会话管理功能。

**规格用户故事覆盖：** 15–19（Git TUI 兼容）。

## T20：长时间输出与异常关闭时保持资源有界

**Blocked by:** T04、T05、T16。

**What it delivers:** 持续输出、多会话和选择器异常关闭不会使应用无限占用内存、卡死或遗留进程。

**Acceptance criteria:**

- [ ] 覆盖无 View 的持续输出、标题/响铃洪泛、多会话创建销毁、会话重附加和 picker 管道断开。
- [ ] 历史与事件队列遵守已公布上限；退出/错误事件不会因洪泛永久丢失。
- [ ] 取消、启动失败、用户关闭及宿主销毁均在明确截止内完成清理，无失效回调。
- [ ] 从公开宿主/CLI 边界检查运行结果、进程及资源趋势，修复实际泄漏或阻塞，不增加常驻服务。

**规格用户故事覆盖：** 20、23–24、37、41–43、49（稳定性）。

## T21：按需刷新并建立可复现性能基线

**Blocked by:** T10、T20。

**What it delivers:** 空闲终端不持续重绘，并能重复测量启动、内存、CPU、输出吞吐与帧延迟。

**Acceptance criteria:**

- [ ] 验证空闲无持续重绘及未使用能力不额外初始化，界面更新后仍能及时呈现。
- [ ] 记录冷/热启动、空闲/峰值内存、空闲 CPU、输出吞吐、帧延迟的测量方法、环境和基线。
- [ ] 进行基于实际数据的必要优化，回归双入口与选择器，不用静态库体积代替运行内存。
- [ ] 不设置未经验证的绝对性能承诺，测试结果可由他人按同样步骤复现。

**规格用户故事覆盖：** 20、59。

## T22：让外部应用仅凭开发包嵌入终端

**Blocked by:** T05、T09、T10、T12。

**What it delivers:** 独立 C++ 应用不依赖产品内部源码即可使用 DLL、C 接口和 C++23 包装嵌入终端。

**Acceptance criteria:**

- [ ] 外部最小宿主仅消费公开头文件、链接库和 DLL，覆盖会话创建/终止、View 寿命、输入、尺寸、外观、滚动选择、剪贴板、查询和事件。
