# ADR 0007：Windows 启动器与等待语义

状态：已采纳（2026-10-31）。

普通启动让用户打开终端后立即取回 Shell 提示符。脚本通过 `-e` 或 `--stdio` 调用时，需要等交互完成才能使用退出状态或管道结果。Windows 使用同一个 `termole.exe` 承担两个角色。

- **启动器**是公开入口。普通模式下，成功启动 GUI 角色后立即返回 0。`-e` 和 `--stdio` 模式下，启动器等待 GUI 角色退出并转交退出状态。启动器只隐藏为本次启动新分配的控制台，保留调用方已有的控制台。
- **内部 GUI 角色**通过 `--gui` 进入，负责创建窗口、会话和视图。在等待模式下，程序结束并排空输出后，GUI 角色退出。用户提前关闭窗口时，GUI 角色结束本次会话的进程树，并向启动器返回取消状态。

完整退出码表见 [CLI 手册](../cli.md#等待与退出码)，数据流向见 [ADR 0006](0006-terminal-selector-boundary.md)。真实 CMD 和 PowerShell 管道的验证方法见[验证指南](../agents/testing.md)。
