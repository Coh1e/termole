# 独立窗口与会话生命周期

状态：已采纳。

- **轻量独立终端**：一次启动创建一个窗口、一个视图和一个会话。调整窗口大小时会话继续运行。在 Windows、Linux 和 macOS 上，关闭窗口时均须回收该窗口的 Shell 及其子进程，包括仍在运行的 fzf。其他窗口的原会话继续可用，可以执行命令。
- **TUI Applet**：一次调用拥有一个窗口、一个视图和一个会话。用户提前关闭窗口即取消调用，回收本次调用的进程树，并向调用方返回取消状态。
- **本地会话服务**：服务端持有会话和子进程。客户端可选择在关闭视图后保留会话，以便稍后重连。具体用法见[本地会话](../cli.md#本地会话)。
- **嵌入宿主**：宿主决定视图和会话的寿命。销毁视图后，会话可以继续运行并重新附加视图。所有权和销毁顺序见 [SDK 手册](../sdk.md#生命周期)。

独立窗口的设置和尺寸规则见[配置手册](../config.md#窗口尺寸)，Windows 的等待行为见 [ADR 0007](0007-console-launcher-wait.md)。
