# 轻量终端与 Windows Applet 拆票清单

本地终审稿，共 10 张交付票、1 张发布验证票。编号供本轮评审使用。下表只列直接依赖；共享能力在对应平台可用后，下游即可开展，各平台分别记录验收结果。

## 轻量终端

Windows 先验收，Linux 和 macOS 在同一张票上执行相同场景。记录系统、Shell、TUI 及版本，窗口行为留截图或像素证据，文本核对实际输入输出。[轻量终端规格](https://github.com/Coh1e/termole/issues/32)

| 票 | 交付内容 | 该票负责的验收 | 直接依赖 |
| --- | --- | --- | --- |
| T1 | 零配置启动默认 Shell，建立窗口和会话 | 无用户配置时从普通入口启动，显示默认提示符；执行命令得到独立一行 `Termole ready`，还能继续输入。 | 无 |
| T2 | 视图选区复制及向前台程序粘贴 | 三平台分别按惯用方式复制 `Termole 中文 test` 并粘贴，前台程序收到的中文、两个空格和英文大小写逐字一致。 | T1 |
| T3 | 全屏 TUI 随窗口缩放，保留交互状态 | 在 Shell 中启动全屏 fzf，筛选后选中第二项。缩小、放大窗口后分别核对重绘、筛选词和选中项；Enter 返回原选项，原 Shell 能继续执行命令。 | T1 |
| T4 | 取消全屏 TUI 后恢复 Shell | 先打印标记行，再进入 fzf、筛选并按 Esc。标记行恢复可见，fzf 界面清除，光标回到提示符，新命令及其输出可见。 | T1 |
| T5 | 关闭窗口时回收本会话的进程，隔离另一会话 | 打开两个窗口，在第一个运行 fzf 并记录 Shell 和 fzf 的进程标识。直接关闭第一扇窗口，核实两进程均退出；第二个窗口的原会话能执行命令并显示预期输出。 | T1 |

## Windows Applet

交付同一份 Windows x64 便携包和 PowerShell 文件选择示例。验收从 Windows PowerShell 5.1 示例进入，使用单独安装的真实 fzf。分别核对 stdout、stderr 和退出码，界面与输入法交互留真实窗口证据。[Windows Applet 规格](https://github.com/Coh1e/termole/issues/31)

| 票 | 交付内容 | 该票负责的验收 | 直接依赖 |
| --- | --- | --- | --- |
| A1 | 随包交付可运行的选文件示例，通过 `--stdio` 将候选交给 fzf、将选择交回脚本 | 分别使用当前目录和指定目录，仅列出直属文件。Enter 后退出码为 0，stdout 只有选中文件的完整路径。 | T1 |
| A2 | 在开窗前处理无候选、目录无效和缺少 fzf | 空目录返回 1；无效目录、缺少 fzf 分别返回 2。三种情况均不开窗、stdout 为空，stderr 说明原因。缺少 fzf 用含候选的有效目录验收。 | A1 |
| A3 | 让用户在浮窗中取得焦点，通过真实中文输入法选择文件 | 前台召出后可直接输入；后台受激活限制时浮窗可见，点击后可输入。键入拼音、选词并提交，筛出目标，调用脚本收到完整中文路径。基本显示与输入复用 T1。 | A1 |
| A4 | 预览当前候选的文本内容，支持快速切换 | 在示例说明中给出读取上限；超限提示截断，二进制和不可读文件有提示且仍可选。快速切换时预览对应当前候选，搜索和选择可继续。 | A1 |
| A5 | 取消运行预览的 Applet，并把各次调用的结果交还对应脚本 | 分别按 Esc 和关窗，退出码为 130、stdout 为空，示例退出前本次 fzf 和预览进程均退出。另用两组候选交错操作：取消第一扇，在第二扇继续预览并选中，第二个脚本收到自己的路径及退出码 0。通用关窗回收与会话隔离归 T5。 | A4、T5 |
